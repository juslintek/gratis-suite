## 🚀 Quick Start

```bash
# Install the core suite
wp plugin install cache-manager --activate
wp theme activate gratis-theme
wp gratis-cache dropin install
wp gratis-cache status

# Or use the installer
wp plugin activate gratis-installer
wp gratis-install all
```

## 🏗️ Architecture

See [ARCHITECTURE.md](./ARCHITECTURE.md) for technical details.

## 🎯 Principles

1. **Free by default** — Nothing useful is locked behind a paywall
2. **Zero external dependencies** — Pure PHP, no Composer, no npm build steps
3. **WordPress-native** — CPTs, taxonomies, meta, REST API, block editor
4. **WP-CLI first** — Every feature accessible via command line
5. **Lightweight** — Each plugin <500KB, 15ms response with all active
6. **Interoperable** — Plugins enhance each other when co-active
7. **SQLite compatible** — All plugins work with gratis-db SQLite mode
8. **Horizontally scalable** — Redis sessions, S3 offloading, health endpoints
9. **WordPress 7.0 ready** — Abilities API integration for AI agents
10. **Non-invasive** — No nag screens, no tracking, no "Pro" version
